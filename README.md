# 🎮 Loja de Games Retrô

Projeto acadêmico desenvolvido para a CP3 da disciplina de C# Development da FIAP.

## Sobre o projeto

Aplicação desenvolvida em C# utilizando Windows Forms, simulando uma loja de jogos retrô.

### Funcionalidades
- Splash Screen com carregamento automático
- Menu principal
- Catálogo de jogos retrô
- Registro de pedidos
- Relatório de vendas com cálculo do faturamento

### Tecnologias utilizadas
- C#
- .NET
- Windows Forms
- Git e GitHub
